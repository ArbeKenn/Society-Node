Основные буквы (типы элементов)
m — Method (Метод). Функция, которая принадлежит какому-либо классу.
f — Function (Функция). Обычная функция (определенная через def), которая не привязана к классу.
c — Class (Класс). Шаблон для создания объектов (определяется через class).
v — Variable (Переменная). Локальная или глобальная переменная, хранящая данные.
p — Parameter (Параметр). Переменная, которая передается в функцию или метод в качестве аргумента.
P — Property (Свойство). Геттер или сеттер, используемый для доступа к данным объекта (например, методы с декоратором @property).
k — Keyword (Ключевое слово). Зарезервированное слово языка Python (например, def, if, for, class, import).

Буквы модификаторов и контекста
a — Attribute (Атрибут). Переменная или свойство, привязанное к определенному объекту или модулю.
t — Type (Тип) или Typing (Аннотация). Отображается, когда вам предлагают выбор встроенных типов данных, таких как str, int, list, или пользовательских TypeVars.
n — Namespace (Пространство имен). Указывает на модуль или пакет (например, если вы импортируете math).
